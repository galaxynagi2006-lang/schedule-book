Google連携（バイト予定・manaba の課題・通知）

はじめての連携の手順（約5分・最初の1回だけ）
  1. 下のボタンからテンプレートを開き、「コピーを作成」を押す テンプレートをコピーする
  2. コピーしたスプレッドシートのメニュー「スケジュール帳」→「① 初期設定」を押し、表示される許可を「許可」する
  3. 「拡張機能」→「Apps Script」→ 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行：自分／アクセス：全員 で「デプロイ」
  4. メニュー「スケジュール帳」→「② アプリに登録する情報」のQRコードを、下の「ほかの端末に設定を移す」の「QRコードを読み取る」で読み取る（パソコンなら「このパソコンのアプリに登録する」を押す）

※ 1〜3はパソコンで行ってください（スプレッドシートのスマホアプリでは「スケジュール帳」メニューが使えません）。QRコードが使えないときは、同じ画面のURLと合言葉を下の2つの欄に貼ります。

データはあなたの Google アカウントの中だけで処理され、ほかの人（アプリの開発者を含む）には送られません。

※テンプレートを使わない場合は「作る」で作り、Apps Script の WRITE_TOKEN にも同じ文字列を入れる

下のボタンで、登録したURLをブラウザの新しいタブで開きます。表示された内容で原因がわかります。

  • {"events": … のような文字 → 連携は正常です。少し待ってから「今すぐ同期」を押してください
  • 合言葉が一致しません → 合言葉が違います。「② アプリに登録する情報」を読み取り直してください
  • Google のログイン画面・「ファイルを開くことができません」 → デプロイが止まっているか、アクセスが「全員」になっていません。Apps Script の「デプロイを管理」を確認してください

撮影・発表用のデモ表示

使い方

朝・帰宅後・寝る前に、今日と明日のバイトと今やるべき課題を1つの画面で確かめるためのスケジュール帳です。

バイトの見方
  1. 今日のバイトがあるかを大きく表示します。時間とバイト名も出ます。
  2. 明日のバイトも、ここで確かめられます。
  3. 押すと今後のバイトの一覧が開きます。✕ で消せます。
課題の見方
  1. ○ を押すと完了です。もう一度押すと未完了に戻ります。
  2. 課題の行を押すと編集できます（名前・締切・所要時間）。削除は編集画面のいちばん下です。
  3. 締切までの残り時間です。色が優先度を表します。
    赤 急ぎ（残り時間が作業時間の2倍未満、または12時間未満）
    黄 注意（5倍未満、または36時間未満）
    緑 余裕あり
  4. 印は、manaba から取り込んだ課題の種類（レポートなど）や「毎週」の課題を表します。

課題は「締切までの残り時間 ÷ 作業にかかる時間」が小さい（＝急ぐ）順に並びます。締切を過ぎた課題は「期限切れ」として一番上に出ます。遅れそうな課題には、色の付いた注意書きが出ます。下の「これから7日の見通し」では、授業・バイトを除いた空き時間で課題が間に合うかを知らせます。

課題・バイトを登録する
  1. 右下の ＋ で開きます。シフト表の写真からバイトを、時間割の画像から授業を、まとめて登録できます。
  2. タイトル・種別（課題／アルバイト）・締切を入れて「登録する」。
  3. 所要時間は空欄でOK。AI が課題の内容から作業時間を推定します。自分で分を入れることもできます。
  4. 毎週同じ曜日・時刻が締切の課題は「毎週くり返す」に。締切の7日前から毎週一覧に出ます。
完了したら

○ を押して完了にすると、実際にかかった時間を聞かれます。選んで記録すると、次からの AI の推定が自分のペースに合っていきます（記録しないときは ✕）。

タイムライン
  1. 空いている時間に、急ぐ課題から自動で作業時間を割り当てます（赤の課題が先）。
  2. 時間割の授業の時間は避けます。
  3. 長い課題は、授業の合間に分けて置きます（「2/3」は3回に分けた2回目）。
  4. バイトの前後30分は移動の時間として空けます。課題に使える時間帯は設定で変えられます。

上の「今日／明日」で切り替えます。明日の計画は、今日の計画どおりに進めた場合のものです。

Google・manaba との連携と通知
  • 設定の「Google連携」の手順で一度つなぐと、Googleカレンダーのバイトの予定と、manaba の課題（Gmail に届く「公開のお知らせ」）が自動で取り込まれます。
  • manaba の「提出のお知らせ」が届くと、その課題は自動で完了になります。
  • 毎朝のまとめメール（今日・明日のバイトと締切が近い課題）と、バイト前の確認メールが届きます。
  • manaba からお知らせが来ない課題は、＋から手で登録するか「毎週くり返す」を使ってください。
困ったとき
  • 同期できない：設定の「同期できないとき」で、連携のURLを開いて原因を確かめられます。
  • スマホとパソコンで内容が違う：データは端末ごとに保存されます。設定の「ほかの端末に設定を移す」のQRコードで連携をそろえてください。
  • 画面が暗い／明るい：設定の「画面の色」で、夜だけ暗く・いつも明るい などを選べます。
  • 機種変更する：設定の「データのバックアップ」で書き出しておくと、新しい端末で読み込めます。

アプリを終了しますか？

もう一度スマホの「戻る」を押しても終了できます。
