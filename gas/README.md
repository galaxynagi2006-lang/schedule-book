# スマートスケジュール帳：Google 連携（Apps Script）

アプリの Googleカレンダー連携・manaba（Gmail）の課題の取り込み・通知は、
**使う人それぞれの Google アカウントの中で動く Apps Script** で行います。
データは本人のアカウントの外（アプリの開発者を含む）には送られません。

一人ひとりにコードを貼ってもらう代わりに、**コード入りのスプレッドシート（テンプレート）を
「コピーを作成」してもらう**だけで使えるようにしています。

---

## 配布する人：テンプレートを1回だけ作る

1. Google スプレッドシートで新しいスプレッドシートを作る
   （名前の例：`スマートスケジュール帳 連携（テンプレート）`）
2. メニュー「拡張機能」→「Apps Script」を開き、最初からある `コード.gs` の中身を
   [calendar-export.gs](calendar-export.gs) の内容に**丸ごと置き換えて保存**する
3. スプレッドシートの右上「共有」→「一般的なアクセス」を
   **「リンクを知っている全員」・「閲覧者」**にする
4. スプレッドシートのURLの末尾の `/edit…` を **`/copy`** に変えたものが配布用のリンクになる
   - 例：`https://docs.google.com/spreadsheets/d/〇〇〇/copy`
   - このリンクを開いた人には「コピーを作成」ボタンが表示される
5. アプリの `index.html` の `GAS_TEMPLATE_URL` にこのリンクを入れると、
   アプリの「⚙️ 設定」→「Google連携」→「はじめての連携の手順」に「テンプレートをコピーする」ボタンが出る

> **注意**：テンプレートそのものでは「① 初期設定」を実行しないでください。
> 合言葉や設定シートがコピー先に引き継がれてしまいます。
> 自分で使うときも、テンプレートを**コピーしたもの**を使ってください。

コードを更新したときは、テンプレートの Apps Script を新しいコードに置き換えます。
（すでにコピーした人のスプレッドシートは自動では更新されないので、必要なら同じように置き換えてもらう）

---

## 使う人：連携の手順（約5分・最初の1回だけ）

手順1〜3は**パソコン**で行ってください（スプレッドシートのスマホアプリでは「スケジュール帳」メニューが使えません）。

1. 配布されたリンクを開き「**コピーを作成**」を押す
2. コピーしたスプレッドシートのメニュー「**スケジュール帳**」→「**① 初期設定**」を押す
   - 「承認が必要です」→ 自分のアカウントを選ぶ →
     「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」→「許可」
   - 設定シートの作成・合言葉の作成・自動実行（通知）の設定がまとめて終わる
3. 「拡張機能」→「Apps Script」→ 右上の「**デプロイ**」→「**新しいデプロイ**」
   - 歯車から種類「**ウェブアプリ**」
   - 次のユーザーとして実行：**自分** ／ アクセスできるユーザー：**全員** →「デプロイ」
4. スプレッドシートに戻り、メニュー「スケジュール帳」→「**② アプリに登録する情報**」を開く
   - **スマホで使う**：表示された**QRコードをスマホのカメラで読み取る**だけ。アプリが開いて、連携が自動で登録される
     （ホーム画面に追加したアプリはブラウザと保存場所が別なので、アプリの「⚙️ 設定」→「📷 QRコードを読み取る」で読み取る）
   - パソコンのアプリに登録済みなら、アプリの「⚙️ 設定」→「📲 ほかの端末に設定を移す」でQRコードを出し、
     スマホのアプリで読み取ると、APIキーも含めて同じ設定になる
   - **パソコンで使う**：「このパソコンのアプリに登録する」を押す
   - QRコードが使えないとき：同じ画面の URL と合言葉を、アプリの「⚙️ 設定」→「Google連携」に貼る
   - 合言葉は、アプリが予定や課題を読むときと、シフト表を書き込むときの両方に使います
     （URLだけが他人に知られても、合言葉がなければ中身は見られません）
   - デプロイしたのにQRコードが出ないときは、デプロイ後に表示された「ウェブアプリ」のURL（…/exec）を
     シート「設定」の `WEBAPP_URL` に貼ってから、もう一度開く
   - アプリで「Apps Script につながりません」と出て、URLを開くと「ファイルを開くことができません」となるときは、
     QRコードのURLが止まったデプロイのものになっている。「デプロイを管理」の有効なウェブアプリのURLを
     `WEBAPP_URL` に貼ると、QRコードにはそのURLが使われる

### 設定を変えたいとき
シート「設定」の「値」の列を書き換えるだけで変わります（コードを触る必要はありません）。

| 項目 | 内容 |
|---|---|
| KEYWORDS | タイトルにこの言葉を含む予定をバイトとして扱う（カンマ区切り。「なし」で全部の予定） |
| MORNING_HOUR | まとめメールを送る時刻（変えたら「① 初期設定」をもう一度押す） |
| JOB_REMINDER_MIN | バイト開始の何分前に確認メールを送るか |
| DEADLINE_REMINDERS_MIN | 締切の予定の通知（分前。1440 = 前日） |
| MANABA_ENABLED | manaba の課題メールを読むか（TRUE / FALSE） |
| MANABA_HIDE_KINDS | まとめメール・カレンダーに出さない課題の種類（例：アンケート） |

### AI のひとこと（任意）
まとめメールに AI のひとことを付けるには、Apps Script の「プロジェクトの設定（歯車）」→
「スクリプト プロパティ」に `GEMINI_API_KEY` という名前で Gemini の APIキーを追加します。

### やめたいとき
メニュー「スケジュール帳」→「自動実行（通知）を止める」を押し、
Apps Script の「デプロイを管理」でウェブアプリを「アーカイブ」すると、外からは使えなくなります。

## 以前からの単体スクリプトで使っている場合
スプレッドシートを使わず、コードを `script.google.com` に直接貼って使っていた場合もそのまま動きます。
設定は `DEFAULT_CONFIG` の値を直接書き換えてください（以前の `CONFIG` から名前が変わりました）。
`WRITE_TOKEN` を設定している場合は、アプリの「⚙️ 設定」→「Google連携」にも同じ合言葉を入れてください
（読み取りにも合言葉が必要になったため、入れないと同期できません）。
